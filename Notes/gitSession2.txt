Steps for Pulling GitHub Repo into local repo:- 
-----------------------------------------------
1. First Start Process
git  init
2.  Add Github repo to local repo
	git remote add origin <repo url>
git remote add origin https://github.com/venugopalarumuru1978/SimpliRepo.git
3.  Now use pull command to get repo
	git pull --rebase  origin master 
------------------------------------------------
Steps for Pushing files from local repo to github repo
------------------------------------------------
1.  First Start Process
git init
2.  add file to the staging area
git  add  <file names>
	to add all files
	git add .
	to add specific file
	git add <file name>
3.  Check the added files as follow
	git status
4.  Make commit for pushing files
	git commit -m  "commit msg"
5.  now push files
	git push -u origin master
