What is a Variable?
		It is a named memory location to store value temply. 

			As per JavaScript, variables can be declared as follows

			var/let  <variable name> = <Value>

		Variable Names must be one word and it should starts with an alphabet.

		var x = 100;
		var y = 12.45;

		As per the java script, there 4 different data types based on value assigned to variable. 

		Number  =   integers / float (decimal)
		String  = text
		Boolean = true / false
		Any  = to store any type of value.

Every  Script Language is a function based script language. 
How to create a user defined function?

	function  <fun_name>(arg1, arg2,...)   // defining the function
	{
		body of the function
	}

How to execute a user defined function?

	<fun_name>(argVal1, argVal2, ....);   // calling the function
--------------------------------------------
A function can take arguments  and can return a value. 

An argument is a value which we pass at the time of function calling. A functions any no of arguments. 

A function can return value. 


While creating a function there different combinations 

1.  Without arguments and without return value
2.  With arguments and without return value
3.  With arguments and with return value
-------------------------
Variables are two types based on their location

	1.  Global Variables   :-   The variable which are declared in begining ofthe programming(not in any fun).
					these are accessed in all the functions of the program.
					usually these variables are declared with "var" keyword
	2.  Local Variables :-   these variables are declared within the function with let variable. 
				these are accessed only in that function.
