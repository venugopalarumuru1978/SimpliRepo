useEffect(()=>{
        setStr('This is use Effect hook');
    });

this will get executed whenever page is re-renders again and again

useEffect(()=>{
        setStr('This is use Effect hook');
    },[]); // empty array

this will get executed only once when page is renders

useEffect(()=>{
        setStr('This is use Effect hook');
    },[statevar, propvar]);

this will get executed again and again when ever state variable modifies / updates along with first time.

HTTP Request Types :-  GET, POST, DELETE, PUT

	to use these all request types, axios package can be used. 

	install axios module as follows
	
	npm install axios

	axios.get("url") = GET
	axios.post()  = POST
	axios.delete() = DELETE
	axios.put() = PUT
